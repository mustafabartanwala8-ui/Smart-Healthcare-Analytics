# Smart-Healthcare-Analytics

## Project Overview

This project explores healthcare data using Tableau to understand patient demographics, BMI categories, glucose levels, cholesterol levels, and health conditions such as heart disease and diabetes.

## Objectives

- Analyze patient distribution across different age groups.
- Explore BMI categories and their distribution.
- Examine heart disease prevalence across age groups.
- Compare glucose levels by diabetes status.
- Analyze cholesterol levels by heart disease status.
- Explore heart disease prevalence by smoking and alcohol status.
- Present healthcare insights through an interactive dashboard and story.

## Tools Used

- Tableau Public / Tableau Desktop
- Healthcare Dataset (CSV)
- GitHub

## Key Observations

- Normal-range BMI was the largest BMI category in the displayed chart.
- The displayed heart disease prevalence was approximately 31.21% for smokers and 28.72% for non-smokers.
- The displayed prevalence was approximately 30.32% for alcohol consumers and 29.64% for non-consumers.
- The age-based heart disease chart requires validation before drawing firm conclusions.

These observations are descriptive and do not establish causation.

## Limitations

- Findings are based on the available dataset and chart observations.
- Some age-based heart disease values should be verified against the source data.
- The `health_risk_score` field was reported as constant at 100, so it does not distinguish risk levels in this dataset.
- Observational associations do not prove that a factor causes a health condition.
